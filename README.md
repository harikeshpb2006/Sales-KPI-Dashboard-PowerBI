# Sales KPI Dashboard – Power BI

## Project Overview

This project is a Sales KPI Dashboard created using Power BI and MySQL.

The dashboard helps analyze sales performance based on region, category, product, salesperson, and time.

## Tools Used

- Power BI
- MySQL
- SQL
- DAX

## Key Performance Indicators

- Total Sales: ₹1.39M
- Total Profit: ₹264.43K
- Total Quantity: 170
- Total Orders: 30

## Dashboard Features

- Sales by Region
- Sales by Category
- Sales by Product
- Sales by Salesperson
- Sales Trend
- Region filter
- Category filter
- Product filter
- Salesperson filter

## Files Included

- `Sales_KPI_Dashboard.pbix` – Power BI dashboard
- `sales_data.sql` – SQL database and sales data creation script

## Conclusion

The dashboard provides an interactive view of sales performance and helps identify important sales trends and business insights.
